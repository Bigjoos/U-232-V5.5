## 🧬 What is U-232?

U-232 is a BitTorrent tracker source rooted in the original **TBDev / Bytemonsoon** lineage, extended and evolved over multiple generations.

“Chaos Edition” represents a **full modernization pass**:
- bringing legacy code forward to modern PHP standards
- improving security across the stack
- cleaning up years of mixed database and procedural patterns
- preparing the codebase for future development

This is not a rewrite — it’s a **surgical evolution**.

---

## ⚙️ Modernization Highlights

- PHP **8.4+ compatibility**
- PDO database layer (legacy calls being phased out)
- Prepared statements across updated modules
- Full **UTF8MB4** support
- CSRF protection framework
- Argon2id password hashing
- Two-Factor Authentication (2FA)
- Bootstrap 5.3 UI modernization
- Memcached integration
- API v3 support
- Improved logging, debugging, and internal tooling
